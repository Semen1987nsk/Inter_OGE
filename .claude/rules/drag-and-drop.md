# Drag & Drop

Всё вытекает из главного принципа «полная имитация реального мира»:
любой предмет на сцене — физический объект, взять можно с любой точки
и положить в любую другую валидную, включая обратно в комплект.
Реверсивно, без блокировок «только через крестик».

- Источник истины — `accepts: AttachKind[]`. Drop-zone подсветилась
  ⇔ drop ДОЛЖЕН пройти.
- Реверсивность: cyl на весах ↔ cyl в мензурке ↔ cyl в комплекте.
- Карточка `[status='placed']` = drop-zone для возврата + dashed
  контур + «← на столе»; data-draggable динамически снимается.
- Visual `[data-dragging='true']` overlay → `visibility: hidden`
  (нет «задвоения» оригинал + ghost).
- Ghost positioning: учитывать `grabOffset = (cursor - sourceCenter)`
  при pointerdown, иначе цилиндр прыгает.

Все комбинации источник × цель × предусловие зафиксированы матрицей в
`.business/спеки/2026-05-06-drag-matrix-kit-1.md` — применимо ко всем
китам, не только №1.

Идентичный drag&drop UX во всех опытах: ghost у курсора, source-карточка
как «пустая ячейка» с dashed border, drop-hover подсветка зоны.

Анти-паттерн: «умные» drop-зоны, угадывающие что бросили.
