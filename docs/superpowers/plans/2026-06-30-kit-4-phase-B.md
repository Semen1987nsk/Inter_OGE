```

  readonly timestamp: number;
  readonly task: LensTaskId;   // NEW (default 'A-power' для существующих веток)
  readonly d_mm: number;
  readonly f_mm: number;
  readonly F_mm: number;

```
Для task B: `d_mm=f_mm=twoF_mm=objectDistanceMm` (при равенстве d=f=2F), `F_mm=twoF/2`, `D_dptr=1000/F_mm`.

**Журнал (specs.ts):** `FOCAL_2F_SPEC` (experimentId `'4.2'`, kitId `'kit-4'`), колонки:
- `twoF_mm` — label `'2F'`, source `direct`, unit `мм`, format `int`.
- `F_mm` — label `'F'`, source `derived`, unit `мм`, format `int`, tolerance `0.05`, `expectedFromRow: (r) => (r.twoF_mm ?? 0) / 2`.

**lab-optical-bench (НОВЫЕ возможности):**
- Рендерит стрелку-предмет (upright) у гнезда предмета, высота `ARROW_H`, двигается с `setObjectDistanceMm`.
- Проецируемое изображение масштабируется по истинному |Γ| = `|imageDistance(F,d)/d|`, клампим в `[0.2, 3]`. Трансформ inner-группы: `translate(x,y) scale(1, -gammaAbs)`. При d=2F (|Γ|=1) высота изображения = высоте предмета.
- `setSizeMatch(on: boolean): void` — визуальная подсветка «размеры равны» (класс на обе стрелки). Без новых параметров масштаба (масштаб считается внутри из object/lens/screen).
