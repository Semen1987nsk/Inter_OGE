## Решения дизайна Фазы C (утверждено владельцем 2026-06-27)

1. **График — обе ВАХ наложены.** Резистор (прямая через 0) + лампочка (вогнутая кривая) на ОДНИХ осях разными цветами → контраст «линейный vs нелинейный» (суть опыта). `lab-graph` расширяется до мульти-серии.
2. **Снятие точек — ручное, точка-за-точкой** (как measurements): ставим U → замыкаем ключ → читаем I → записываем. Точка идёт в журнал + в серию графика. ~6 точек на элемент. Переиспользуем паттерн журнала/записи.
3. **Выбор элемента — физический drag** (как в Фазе A): две карточки (резистор R1 + лампочка); ученик тащит одну в гнездо «Элемент». Накопленные серии обоих элементов остаются на графике одновременно.
4. **Модель лампы — аналитическая** (не общий солвер): `lampCurrent(U)` монотонно-вогнутая, проходит через номинал (4,8 В → 0,5 А). `R_cold`/`k` затюнены под номинал.

## Task 1: CircuitModel — нелинейная модель лампы

**Files:** Modify `kit-3-circuits/src/physics/circuit/CircuitModel.ts`; `__tests__/CircuitModel.test.ts` (расширить).

**Interfaces:**
- Consumes: существующий `guard()` helper в CircuitModel (бросает RangeError на non-finite).
- Produces: `lampCurrent(U_V: number): number` (А, нелинейно), `lampResistance(U_V: number): number` (Ом, =U/I, при U=0 → `LAMP_R_COLD`), константы `LAMP_R_COLD=2.4`, `LAMP_K=14.4`, `LAMP_RATED_U=4.8`, `LAMP_RATED_I=0.5`.

**Модель (вывод):** нить греется → R растёт с током: `R(I) = R_cold + k·I`. Тогда `U = I·R(I) = R_cold·I + k·I²`. Решая квадратное относительно I:
`I(U) = (−R_cold + sqrt(R_cold² + 4·k·U)) / (2·k)`.
Монотонно возрастает, вогнута (dI/dU = 1/sqrt(R_cold²+4kU) убывает), I(0)=0. Тюнинг под номинал: при U=4,8 → I=0,5 ⇒ `R_cold + 0,5k = 9,6`; берём `R_cold=2,4` (холодная ≈ в 4 раза ниже горячей 9,6) ⇒ `k=14,4`.

```ts
/** Лампа накаливания (ФИПИ 4,8 В · 0,5 А): нить греется → R растёт с током. */
export const LAMP_R_COLD = 2.4; // Ом, холодная нить
export const LAMP_K = 14.4;     // Ом/А, рост R с током (тюнинг под номинал)
export const LAMP_RATED_U = 4.8;
export const LAMP_RATED_I = 0.5;

/**
 * Сила тока через лампу I(U) [А] — нелинейная вогнутая ВАХ.
 * Модель R(I)=R_cold+k·I ⇒ U=I·(R_cold+k·I) ⇒ I=(−R_cold+√(R_cold²+4kU))/(2k).
 * Монотонна, вогнута, I(0)=0, проходит через номинал (4,8 В → 0,5 А).
 */
export function lampCurrent(U_V: number): number {
  guard(U_V);
  if (U_V < 0) throw new RangeError(`U must be >= 0, got ${U_V}`);
  if (U_V === 0) return 0;
  return (-LAMP_R_COLD + Math.sqrt(LAMP_R_COLD * LAMP_R_COLD + 4 * LAMP_K * U_V)) / (2 * LAMP_K);
}

/** Сопротивление лампы R(U)=U/I [Ом]; при U=0 → R_cold (нить холодная). */
export function lampResistance(U_V: number): number {
  guard(U_V);
  if (U_V < 0) throw new RangeError(`U must be >= 0, got ${U_V}`);
  if (U_V === 0) return LAMP_R_COLD;
  return U_V / lampCurrent(U_V);
}
```
