**Сноска (4) — дословный перечень опытов:**
> «− измерение оптической силы собирающей линзы, фокусного расстояния собирающей линзы
> (по свойству равенства размеров предмета и изображения, когда предмет расположен в двойном

### 4.1. Экран `lens-bench` (опыты 4.1/4.2/4.4/4.5) — мульти-таск A/B/C/D
- **Сцена:** оптическая скамья (направляющая ≥700 мм, см-шкала). Лоток с приборами:
  осветитель-предмет (светящаяся стрелка), собирающая линза 1/2, рассеивающая линза 3, экран.
- **D&D-сборка (канон §26):** перетащить осветитель/линзу/экран из лотка в гнёзда скамьи
  (`bench-slot-*`, единый префикс — одна точка регистрации), затем **двигать каретки вдоль скамьи**.
- **Ключевой механизм (одобрено):** ученик **двигает экран до резкости**. Реальное проецируемое
  изображение (перевёрнутая стрелка) рендерится на экране; резкое в плоскости изображения,
  размывается ∝ |позиция_экрана − плоскость_изображения|. Позиции d (предмет→линза) и
  f (линза→экран) читаются по см-шкале скамьи.
- **Opt-in оверлей** (кнопка, по уроку В4): 3 главных луча (параллельный→через F; через центр;
  через F→параллельный) + метки F и 2F. По умолчанию скрыт (видно физическое изображение).
- **Задачи:**
  - **A (4.1):** одна линза (F=100 или 50), навести резкость, снять d/f → F → D=1/F.
  - **B (4.2):** предмет в 2F; добиться равенства размеров (Γ=1) и резкости → 2F → F=L/2.
  - **C (4.4):** двигать предмет по 5 зонам; в **категориальные колонки** журнала писать
    действит./мнимое + прямое/перев. + увелич./уменьш. + числовое Γ.
  - **D (4.5):** сложить две линзы (соб.1+соб.2 → F≈33 мм; соб.+рассеив. → F растёт),
    измерить F_комб; правило D_комб = ΣD.

### 4.2. Экран `refraction` (опыты 4.3/4.6) — мульти-таск A/B
- **Сцена:** круговой транспортир (планшет) с градусными делениями; **полуцилиндр**
  (n≈1,5, плоской гранью на линии диаметра, центр транспортира — в середине плоской грани);
  осветитель-2 (узкий луч). **Геометрия:** луч из воздуха падает на плоскую грань в центре
  → преломляется воздух→стекло (r<i, к нормали) → преломлённый луч идёт по радиусу к
  цилиндрической грани и выходит без преломления (нормальное падение). Читаются i (в воздухе)
  и r (в стекле) от нормали к плоской грани.
- **D&D:** установить полуцилиндр в центр (гнездо) + луч.
- **Механизм (одобрено):** тащить/вращать падающий луч → угол i; преломлённый луч сам
  гнётся по Снеллу (sin i = n·sin r); ученик **читает i и r по круговому транспортиру**.
- **Задачи:**
  - **A (4.3):** снять i, r при одном/нескольких углах → n = sin i / sin r ≈ 1,5.
  - **B (4.6):** варьировать i (несколько значений) → r → таблица + график r(i) (`lab-graph`),
    вывод о нелинейном росте в `#result-panel`.

## 5. Физика (pure, DOM-free, `src/physics/optics/`, Vitest + property-фаззинг ≥12 категорий/50k)

### `LensModel.ts`
- `imageDistance(F_mm, d_mm): number` — формула линзы 1/F = 1/d + 1/f → f = d·F/(d−F).
  d=F → ∞ (изображение в бесконечности); d<F → f<0 (мнимое).
- `magnification(F_mm, d_mm): number` — Γ = −f/d (знак: <0 перевёрнутое, |Γ| размер).
- `focalFromDistances(d_mm, f_mm): number` — F = d·f/(d+f).
- `opticalPower(F_m): number` — D = 1/F [дптр].
- `combinedPower(...D: number[]): number` — ΣD (сложенные тонкие линзы).
- `combinedFocal(...F_mm: number[]): number` — 1/F = Σ(1/Fᵢ).
- `imageProperties(F_mm, d_mm): { kind:'real'|'virtual'; orientation:'inverted'|'upright';
  size:'enlarged'|'reduced'|'equal'; gamma:number }`.
- `guard(...xs)` бросает RangeError на non-finite (зеркало kit-3).
- **Инварианты фаззинга:** d=2F → f=2F, Γ=−1 (равные, перевёрнутое); d>2F → уменьшенное
  действит. перев.; F<d<2F → увеличенное действит. перев.; d<F → мнимое прямое увеличенное;
  D=1/F монотонна; combinedPower = D₁+D₂ ≥ max при двух собирающих; рассеив. (F<0) уменьшает ΣD.

### `RefractionModel.ts`
- `refractionAngle(i_deg, n1, n2): number` — Снелл: r = asin(n1·sin i / n2).
- `refractiveIndex(i_deg, r_deg): number` — n = sin i / sin r.
- `guard` + домен (i∈[0,90); air→glass ПВО нет — но guard на аргументы общий).
- **Инварианты:** i=0 → r=0; air→glass r<i (преломление к нормали); n=sin i/sin r ≈ 1,5
  для всех пар; refractionAngle и refractiveIndex взаимно-обратны.
