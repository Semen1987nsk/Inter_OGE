# Стартовая страница «Комплект виртуального оборудования для ОГЭ по физике» — design

**Дата:** 2026-06-23
**Папка реализации:** `experiments/home/` (этап E1 плана v0.3; заменяет текущий stub)
**Стек:** TypeScript 5.6 strict + Vite 6 + vanilla Web Components (Shadow DOM `open`), без фреймворков. Дизайн-токены — из `@labosfera/shared-spa/styles`.
**Статус:** согласовано в brainstorming 2026-06-23 (4 базовых вопроса + 2 scope + 3 развилки). Источник лучших практик — research-фанаут (launcher UI / edu-hub / motion / a11y), 4 линзы, реальные источники.

---

## 1. Цель и принципы

**Главная задача страницы — удобный, быстрый, красивый выбор эксперимента.** Это витрина продукта мирового уровня (CLAUDE.md: «лучшее в мире, стильно, современно») и одновременно функциональный лаунчер 7 комплектов.

Принципы (из research, привязаны к нашему контексту):
1. **Премиум = мало цвета.** Графит `#06101e` держит ~90% полотна; янтарь `#ffbe0b` — только кольцо прогресса и focus-ring; brand-blue `#3a86ff` — только главный CTA и активный фильтр. Постеры НЕ раскрашивать в разные цвета.
2. **Один постер = одна концепция.** ≤3 смысловых слоя на постере; детали — в drawer.
3. **Focus громкий, не subtle** (класс/проектор/клавиатура): grow + glow + ring.
4. **Запуск опыта за ≤2 клика.** Никаких мастеров «выбери класс → предмет».
5. **Школьность без инфантильности.** Тон инженера-наставника, числа моноширинным, без смайлов/мультяшности.
6. **Доступность — часть продукта, не «потом»** (273-ФЗ, ГОСТ Р 52872, Приказ Минцифры 953, WCAG 2.2 AA).
7. **Производительность как бюджет.** 60fps цель, 30fps без развала на Astra/слабом ПК.

## 4. Постер комплекта — `<kit-poster>`

**Соотношение 3:4** (портрет; ложится на реальные фото оборудования, 3 колонки без вертикального скролла).

Слои (≤3 смысловых):
- Фон — `public/photos/kit-N.png`, `object-fit: cover`.
- Скрим — `linear-gradient(transparent → #06101e ~0.85)` на нижние ~55% (читаемость текста; контраст проверяется в **светлейшей** точке фото, не средней).
- Контент: крупный **№N в золотом progress-кольце** (фокальный якорь) → название (`Комплект №2 · Силы и движение`) → строка-итог моно (`7 опытов · механика · ОГЭ …`). Слева — тонкая цветная полоса-корешок = раздел физики.

**6 состояний** (разделяющая черта премиума от generic):
| Состояние | Вид |
|---|---|
| default | фото + скрим + кольцо |
| hover | `scale(1.04)` + tilt ≤±6° + lift-тень (слой `::after`, анимируем opacity) + янтарный glow-ring; живое SVG-микропревью прибора |
| focus-visible | тот же ring отдельно (клавиатура), `outline-offset` |
| active | лёгкое `scale(0.99)` |
| «скоро» (planned) | `filter: grayscale(.6) brightness(.7)`, бейдж «Скоро» со stroke в цвете фона + `aria-label`, кольцо нейтрально-серое; постер НЕ кликабелен для запуска, но открывает drawer с описанием и ETA |
| loading | скелетон-плейсхолдер |

**Живое микропревью на hover** (вместо video): лёгкая SVG/CSS-анимация прибора комплекта (пружина колеблется, цилиндр погружается). Без видео-ассетов. Появляется по `mouseenter` с задержкой ~250мс намерения; при `prefers-reduced-motion` — статичный кадр.

**Glow:** на каждый `kit-1..7` прекомпьютить акцент-цвет (вытащить из фото на этапе сборки, НЕ в рантайме через canvas) → CSS-переменная `--kit-glow`; на hover радиальный градиент в `::before`, fade 180мс (не blur-фильтр).

## 5. Drawer опытов — `<kit-drawer>` (нативный `<dialog>`)

Выезжает справа, ширина 460px, `slide-in 320мс` + лёгкий backdrop-dim. Реализован на нативном `<dialog>.showModal()` → бесплатно focus-trap, `::backdrop`, top-layer, Esc-закрытие; фон гасим `inert` на `<main>`.

Содержимое:
- Шапка: `КОМПЛЕКТ №N` (надбровь) + название (`aria-labelledby`) + краткое описание (`aria-describedby`) + кнопка «×» (≥44px).
- Список опытов — `<ul>`, каждый опыт строкой: **глагол-результат** («Измерь жёсткость пружины») + бейдж задания ФИПИ (если задан) + статус-точка (не начат / в процессе / сдан) + кнопка «Запустить» (≥44px). Появление stagger 35мс.
- Для planned-комплекта — список будущих опытов серым + строка ETA.

Фокус: при открытии — `lastFocused = document.activeElement`, `dialog.showModal()`, фокус на `h2[tabindex=-1]` (скринридер читает название + список); при закрытии — `lastFocused.focus()`. Состояние открытого drawer и активные фильтры — в URL (`?kit=2&filter=…`) для deep-link учителя.

## 6. Три пути к запуску (удобство выбора)

1. **Постер → drawer → «Запустить»** — основной, ≤2 клика.
2. **Поиск** (top-bar) — индекс по названиям опытов И номерам заданий ОГЭ; результат открывает нужный drawer и подсвечивает конкретный опыт (не просто фильтрует постеры). Ученик ищет «маятник»/«зад. 21».
3. **Sidebar «Готовые опыты»** — live-фильтр: выбор раздела/программы/«только готовые»/прогресса мгновенно гасит нерелевантные постеры (`opacity` + `pointer-events`, без перерисовки сетки). Клик по строке готового опыта → запуск в один клик.

**resume-полоса** (тонкая, над сеткой): «Продолжить · Комплект N — осталось K опытов» + кнопка `→`. Для новичка (нет прогресса) — «Начать с Комплекта №1». Не полноценный billboard.

## 7. Система движения (motion)

Анимируем только `transform` / `opacity`. Тень — отдельный слой `::after` (анимируем `opacity`, не `box-shadow`). `will-change: transform` ставить на `mouseenter`/`focus`, снимать по завершении/`mouseleave` (никогда статически на все 7). `mousemove` для tilt — rAF-троттл.

| Взаимодействие | Длит. | Easing |
|---|---|---|
| stagger-reveal сетки (1 раз) | 70мс × index (последний ~490мс) | decelerate `cubic-bezier(0,0,0.2,1)` |
| hover постера (scale+tilt) | 200мс | M3 standard `cubic-bezier(0.4,0,0.2,1)` |
| уход с hover | 200мс | ease-in `cubic-bezier(0.4,0,1,1)` |
| drawer slide-in | 320мс | decelerate |
| stagger списка опытов | 35–50мс × i | decelerate |
| кольцо при завершении опыта (единственный overshoot) | 360мс | `cubic-bezier(0.34,1.3,0.64,1)` |

`@media (prefers-reduced-motion: reduce)`: база — только `opacity`-fade; tilt/parallax/scale/slide-in отключаются (drawer → мгновенно/короткий fade ≤200мс), кольцо без пульса. Все анимации interruptible. Цель 60fps; проверка: Chrome CPU throttle 6× + paint-flashing — при hover нет вспышек перерисовки, слоёв не больше активных карточек.

## 8. Доступность (273-ФЗ / WCAG 2.2 AA)

- **Сетка** = `role=grid` + ряды `role=row` + постеры `role=gridcell` (кнопка внутри). Roving tabindex (один `tabindex=0`, остальные `-1`); вся стена — один Tab-стоп. Раскладка: `←/→` соседний постер с переносом по рядам, `↑/↓` колонка соседнего ряда, `Home/End` край ряда, `Ctrl+Home/End` край стены, `Enter/Space` → drawer. Число колонок пересчитывать в `ResizeObserver` по фактической ширине (не хардкод).
- **`scrollIntoView({block:'nearest'})`** при навигации + `scroll-margin-top` = высота sticky top-bar (WCAG 2.4.11 Focus Not Obscured).
- **Drawer** — нативный `<dialog>` (trap/Esc/возврат фокуса), `inert` на фоне.
- **Focus-ring токен** `--focus-ring: 0 0 0 3px #ffbe0b` + `outline-offset: 2px`; на постерах поверх фото — двойное кольцо (тёмная подложка + янтарь) для контраста на светлых и тёмных фото; контраст ≥3:1.
- **Текст поверх фото** — scrim (см. §4), контраст ≥4.5:1 (обычный) / ≥3:1 (крупный) в светлейшей точке; text-shadow только усиление.
- **Переключатель Ученик/Учитель** — `role=tablist` + стрелки. Фильтры sidebar — нативные `<fieldset><legend>` + checkbox/radio, группа в `<nav aria-label="Фильтры">`. Прогресс-кольцо дублировать текстом (`aria-label="Прогресс: 3 из 8 опытов"`).
- **Шрифты self-host woff2** в бандле Vite, `@font-face` относительными путями, **без Google CDN** (офлайн Astra). Полная кириллица обязательна: Inter ✓, JetBrains Mono ✓, **Space Grotesk кириллицу покрывает не полностью** → проверить; при пробелах дисплей-шрифт = Inter (или иной кириллический), `font-display: swap` + системный кириллический fallback.
- **Zoom 200% / reflow 320px** без горизонтального скролла (rem/ch + CSS Grid `auto-fill`/`minmax`, названия не обрезать). Target ≥24px (десктоп) / ≥44px (тач), зазор ≥24px между мелкими целями.

## 9. Архитектура

### Web Components (Shadow DOM open, префикс kit-/role-)
- `<kit-poster>` — постер: props через атрибуты (`num`, `status`, `title`, `meta`, `photo`, `progress`, `--kit-glow`), 6 состояний, микропревью, geometry-нейтрален. CustomEvent `poster-activate` (`composed:true`).
- `<progress-ring>` — SVG-кольцо: `value`/`max`, `stroke-dasharray/offset`, round-cap, обод 8% диаметра, анимация заполнения 700мс при появлении; нейтральный режим для planned.
- `<kit-drawer>` — обёртка над нативным `<dialog>`: `open(kit)`, `close()`, focus-mgmt, список опытов, deep-link.
- `<role-switch>` — tablist Ученик/Учитель; `body[data-role]`; учитель видит planned и доп-инфо.

### Модули (TS, без Web Component)
- `GridKeyboardController` — roving tabindex + раскладка клавиш + `ResizeObserver` пересчёт колонок + `scrollIntoView`.
- `sidebar/filters.ts` — live-фильтр (category/program/ready-only/progress) поверх состояния.
- `search/index.ts` — индекс опытов (название + fipiTask), переход в drawer + подсветка опыта.
- `lib/launch.ts` — диспетчер запуска опыта: web → относительный href `../<kit.path>/?screen=<id>&role=<role>`; Electron — задел на Фазу 2 (`window.electronAPI`). Основан на существующем `src/lib/urls.ts` (переиспользовать, не плодить).
- `lib/reduced-motion.ts` — существует, переиспользовать.

### Данные — `src/data/kits.ts` (расширить)
Добавить к `Kit`: `category: 'mechanics'|'electricity'|'optics'|'thermal'`, `accent: string` (прекомпьютенный `--kit-glow`). К `KitExperiment`: `fipiTask?: string` (по ФИ-9 ОГЭ 2026_СПЕЦ; если неизвестно — бейдж не показывать, **не выдумывать**), `resultVerb: string` (глагол-результат, напр. «Измерь жёсткость пружины»; черновики редактируемы). `brand.ts` — строки нейминга.

Категории (первичная разметка, корректируема): Механика = киты 1,2,5,6; Электричество = 3; Оптика = 4; Тепловые явления = 7.

## 10. Тестирование (стандарт репо: 4 уровня + visual)

- **Unit (Vitest, happy-dom):** `totalExperiments`/целостность `kits.ts` (нет дублей slug/num, photo существует, progress.done≤total); `GridKeyboardController` (геометрия переноса при 1/2/3 колонках, Home/End/Ctrl); `search` (находит по названию и fipiTask); `filters` (live-маска); drawer focus-mgmt (запоминание/возврат триггера).
- **State-machine / DOM:** mount/unmount/reset `<kit-poster>`/`<kit-drawer>`; открытие-закрытие drawer round-trip; роль ученик/учитель меняет видимость planned.
- **E2E (Playwright, реальный ввод):** keyboard-навигация по гриду (стрелки/Enter/Esc, focus-ring видим); drawer open → focus в диалоге → Esc → фокус вернулся на постер; запуск ведёт на правильный href; поиск открывает нужный опыт; `prefers-reduced-motion` отключает анимации; reflow 320px / zoom 200% без горизонт. скролла.
- **Visual baseline** (win32, `toHaveScreenshot` `animations:'disabled'`): стена default, hover/focus постера, drawer открыт, planned-постер, мобильный 1 колонка.
- **a11y:** `@axe-core/playwright` на стене и при открытом drawer (0 нарушений).
- Каждый найденный баг → regression-тест.

**Reality-check перед «готово»** (правило проекта): запуск dev-сервера (`--host 127.0.0.1`, см. известную граблю IPv6), Playwright-скриншоты 1920×1080 + 1366×768, сверка глазами.
