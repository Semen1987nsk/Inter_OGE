## 2. Источник правды (ФИПИ, дословно)

**Комплект №3 (СПЕЦ Прил. 2, сноска 3) — 9 опытов:**
1. измерение электрического сопротивления резистора
2. измерение мощности электрического тока
3. измерение работы электрического тока
4. исследование зависимости силы тока в проводнике (резисторы, лампочка) от напряжения (ВАХ)
5. исследование зависимости сопротивления от длины проводника
6. исследование зависимости сопротивления от площади поперечного сечения
7. исследование зависимости сопротивления от удельного сопротивления
8. проверка правила для напряжения при последовательном соединении проводников
9. проверка правила для силы тока при параллельном соединении проводников (резисторы и лампочка)

**Оборудование (СПЕЦ):** источник 1,5–7,5 В; вольтметр 2-пред. (3 В, C=0,1 / 6 В, C=0,2); амперметр 2-пред. (3 А, C=0,1 / 0,6 А, C=0,02); резисторы R1=4,7±0,5 Ом, R2=5,7±0,6 Ом, R3=8,2±0,8 Ом; набор проволочных резисторов (для R от длины/сечения/ρ); лампочка 4,8 В · 0,5 А; реостат 10 Ом; провода 10 шт; ключ.

**Эталонные значения (методичка `03-indirect-3-circuits.md`):** R1: U=1,5 В, I=0,32 А → R=4,7 Ом (интервал 4,2–5,2); работа на R2: U=2,9 В, I=0,51 А, t=60 с → A=88,7 Дж (75–100); мощность на R3: U=5,7 В, I=0,70 А → P=4,0 Вт (3,5–4,5).

## 3. Парадигма сборки цепи (гибрид «гнёзда + провода») — утверждено

`<lab-circuit-board>` рисует **скелет цепи** текущего опыта: провода-рельсы прорисованы, под каждый прибор — подписанное **гнездо** (`data-dropzone`). Ученик тянет приборы из правой панели в гнёзда (переиспользуем `DragController` + snap-zones). Ключевой **грейдимый выбор** — топология приборов:
- амперметр → последовательное гнездо (в разрыв цепи);
- вольтметр → параллельное гнездо (∥ исследуемому элементу);
- для соединений — два резистора в гнёзда «последовательно» либо «параллельно».

**Валидатор топологии** (`CircuitAssembly`): проверяет, что приборы в правильных гнёздах. Ключ замыкается и приборы «оживают» только при корректной схеме; неверное размещение подсвечивается (педагогика — не запрещаем, а учим). Замыкание ключа → анимация тока (стрелки по рельсам), приборы показывают U/I с шумом и ценой деления.

**НЕ делаем** свободный роутинг проводов клемма-в-клемму и общий нодальный солвер (вне объёма волны; гнёзда покрывают ФИПИ-навык «приборы подключены правильно»).

## 4. Симуляция — `CircuitModel` (pure, `src/physics/circuit/`)

Не общий солвер, а **аналитика по ограниченным топологиям опытов**:
- одиночный R: I=U/R, R=U/I, P=U·I, A=U·I·t;
- ВАХ: резистор I=U/R (линейно); лампочка — нелинейная R(T) (рост R с нагревом, монотонная вогнутая ВАХ);
- проволочный резистор: R=ρ·l/S (зависимости от l, S, ρ раздельно);
- последовательное: I общий, U=U1+U2, R=R1+R2;
- параллельное: U общее, I=I1+I2, 1/R=1/R1+1/R2.
Реалистичный шум приборов + квантование по цене деления (как в методичке). Бросает `RangeError` на невалидных входах. Vitest 100% + property-фаззинг (≥12 категорий инвариантов: R>0, P=UI≥0, последовательное R≥max(Ri), параллельное R≤min(Ri), и т.д.).

## 5. Приборы `lab-*` (реалистичные, как kit-1/2; shadow DOM, `svg[hidden]{display:none}`)

`lab-power-source` (рег. напряжение 1,5–7,5 В, ручка/шкала), `lab-voltmeter` (2-пред. 3/6 В, шкала+стрелка/LCD), `lab-ammeter` (2-пред. 3/0,6 А), `lab-resistor` (варианты R1/R2/R3 + проволочные ρlS с параметрами l/S/материал), `lab-lamp` (4,8 В, светится при токе), `lab-rheostat` (10 Ом, ползунок), `lab-key` (замкнут/разомкнут), `lab-wire` (рельс/соединение), `lab-circuit-board` (монтажная панель со скелетом+гнёздами). Геометрический API клемм для привязки стрелок тока.

## 6. Экраны (9 опытов → 4 экрана)

| Экран (slug) | ФИПИ-опыты | Паттерн-эталон |
|---|---|---|
| `measurements` «Измерения тока» | 3.1 R резистора · 3.2 мощность · 3.3 работа тока | friction (мульти-таск: переключатель резистор R1/R2/R3 + задача) |
| `iv-curve` «ВАХ» | 3.4 I(U) для резистора и лампочки | spring-elastic (свип + график I–U; лампа нелинейна) |
| `wire-resistance` «Сопротивление проводника» | 3.5 R(длина) · 3.6 R(сечение) · 3.7 R(ρ) | мульти-таск (набор проволочных резисторов) |
| `connections` «Соединения» | 3.8 правило напряжений (последов.) · 3.9 правило токов (параллельн.) | мульти-таск (2 резистора + лампочка) |

Каждый экран — `IScreen` в `KitShell`; нав-бар + резюме как в kit-2.

Новые SPEC в `_shared-spa/.../journal/specs.ts`: `RESISTANCE_SPEC`, `POWER_SPEC`, `WORK_CURRENT_SPEC`, `IV_CURVE_SPEC`, `R_LENGTH_SPEC`, `R_AREA_SPEC`, `R_RHO_SPEC`, `SERIES_VOLTAGE_SPEC`, `PARALLEL_CURRENT_SPEC`. Колонки: direct (U, I, t, l, S, ρ — прибор/паспорт) + derived (R, P, A, R_теор — с tolerance по ФИПИ-интервалам). 3 режима записи (ключ `'kit-3'`), `verifyRow`, `parseRu`.

## 10. Декомпозиция плана (фазами — волна большая)

- **Фаза A — инфра + вертикальный срез:** package-скелет kit-3; `CircuitModel` (одиночный R) + тесты; базовые приборы (source/voltmeter/ammeter/resistor/key/wire/circuit-board); `CircuitAssembly` (слоты+валидатор+ток); экран `measurements` опыт 3.1 end-to-end (журнал, selfcheck, reality-check). Это доказывает паттерн.
- **Фаза B:** опыты 3.2, 3.3 на экране `measurements` (мощность, работа — переключатель задачи).
- **Фаза C:** экран `iv-curve` (3.4) + `lab-lamp` нелинейная.
- **Фаза D:** экран `wire-resistance` (3.5–3.7) + проволочные резисторы.
- **Фаза E:** экран `connections` (3.8–3.9) + `lab-rheostat` при необходимости.
- **Фаза F:** каталог (kit-3 status ready, done по опытам), REFERENCE §30, постер kit-3 в цвет, финальные гейты.

## 11. Вне объёма (YAGNI)

- Общий нодальный солвер и свободный роутинг проводов клемма-в-клемму.
- Реостат как делитель напряжения сверх ФИПИ (реостат используется только если опыт требует; базово ФИПИ №3 не содержит отдельного «опыта на реостат» — это бонус, решим отдельно при необходимости, `isFipi:false`).
- Тепловыделение/Джоуль-Ленц как отдельный опыт (не в ФИПИ-перечне №3 → бонус, не сейчас).
