# Опыт 1.4 «Исследование F_арх(ρ жидкости)» — режим в табе «Архимедова сила»

**Дата:** 2026-05-24 · **Кит:** kit-1-hydrostatics, экран `archimedes` · **Ветка:** TBD (стек на `feat/kit2-friction-work` ради shared journal-фикса)

## Цель
ФИПИ-опыт 1.4 «исследование зависимости архимедовой силы от плотности жидкости»
(вода ↔ соляной раствор). Гибрид-правило: НЕ новый экран, а **режим-тумблер**
внутри существующего таба «Архимедова сила» (1.2).

## ФИПИ-якорь
Спецификация КИМ ОГЭ-2026, Прил. 2, стр. 16: «исследование зависимости архимедовой
силы … от плотности жидкости». Соль+палочка в kit-1 — ТОЛЬКО для приготовления
раствора в 1.4 (REFERENCE §18). ρ раствора ФИПИ жёстко не задаёт (ученик готовит сам).

## Что уже готово
- Физика: `archimedesForceN(rho_kg_m3, V_m3)` уже принимает плотность (ArchimedesCalc.ts:30).
- `tables.ts`: `LIQUIDS = { water: {rho:1000} }`, `LiquidId='water'`, коммент «раствор появится в 1.4».
- Экран: `pourWater`, `placeBeaker`, `inWater`-гистерезис, beaker 250мл, степпер 1-6, журнал v2.
- per-task SPEC паттерн отработан на friction (#currentSpec).
- lab-salt-set (NaCl+палочка) есть как элемент (пока не интерактивен).

## Решение

### A. Модель раствора (инкрементально солью) — `tables.ts`
- Ученик тащит `lab-salt-set` в стакан + перемешивает → ρ растёт ступенями.
- Реализм NaCl: насыщение ~1200 кг/м³ (20°C). **3 порции соли, 4 точки**:
  `1000 (вода) → 1070 → 1140 → 1200 (насыщ., cap)`. Δρ≈70/порция. Это симуляционная
  аппроксимация (не жёсткая ФИПИ-константа) — задокументировать в docstring.
- Свыше cap соль не растворяется → announce «раствор насыщен».
- `LiquidId = 'water' | 'solution'`; текущая ρ хранится в state (`liquidRhoKgM3`).

### B. Salt-flow (принцип «полной имитации»)
- Drag `lab-salt-set` → стакан (новая snap-zone) → анимация растворения + «перемешать».
- Каждая порция: ρ += шаг, вода визуально чуть мутнеет/желтеет (опц.), announce ρ.
- Реверсивно нельзя (соль не вынуть) — это физично; сброс через reset.

### C. Режим-тумблер (в табе «Архимедова сила»)
- Сегмент-переключатель в header: **«Вода» (1.2)** | **«Раствор» (1.4)**.
- В режиме 1.4: доступна соль; журнал = ARCHIMEDES_LIQUID_SPEC; показывается график.
- Поток 1.4: налить воду → погрузить цилиндр → записать F_арх(вода) → добавить соль →
  записать F_арх → … → 2-4 точки → график + вывод «F_арх ∝ ρ».

### D. Журнал — `ARCHIMEDES_LIQUID_SPEC` (shared specs.ts, experimentId '1.4')
| key | label | source | прим. |
|---|---|---|---|
| idx | № | meta | |
| rho_kg_m3 | ρ, кг/м³ | meta | плотность жидкости (из salt-flow) |
| V_cm3 | V, см³ | meta | объём цилиндра (полное погружение) |
| P_air_N | P возд, Н | direct | |
| P_liq_N | P жид, Н | direct | |
| F_A_meas_N | F_A изм, Н | derived | P_возд − P_жид, tol 0.05 |
| F_A_theor_N | F_A теор, Н | derived | ρ·g·V (НЕ хардкод воды!), tol 0.05 |

`#currentSpec()` в archimedes: режим 1.4 → ARCHIMEDES_LIQUID_SPEC, иначе ARCHIMEDES_SPEC.

### E. График F_арх(ρ)
- kit-1 графика НЕТ. **Порт kit-2 `lab-graph`** в kit-1 (минимально, без переписывания)
  ИЛИ компактный SVG-scatter+line. Ось X = ρ (1000..1200), Y = F_арх. Точки из журнала + линия тренда.
- Показывается в режиме 1.4 при ≥2 точках. Подпись «прямая пропорция F_арх ∝ ρ».

## Definition of Done
1. Режим «Раствор»: соль→стакан→ρ ступенями; F_арх растёт с ρ; 2-4 точки в журнале.
2. Журнал ARCHIMEDES_LIQUID_SPEC; F_A_theor = ρ·g·V (корректно для любой жидкости).
3. График F_арх(ρ) виден при ≥2 точках, линейный.
4. Режим «Вода» (1.2) не сломан — ARCHIMEDES_SPEC, все тесты зелёные.
5. Тесты: unit (ρ-from-salt, F_A для раствора) · state (режим-switch, salt-flow, SPEC-switch) ·
   e2e (real-mouse: налить→погрузить→записать→соль→записать→график) · visual baseline.
6. typecheck 0, lint 0; browser self-check на :5174 во всех 3 режимах журнала + скрин графика.
