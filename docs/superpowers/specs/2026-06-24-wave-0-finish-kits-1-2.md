## 2. Состав работ и архитектура

### 2.1. Каталог `home/src/data/kits.ts`

**Модель данных.**
- `KitExperiment` получает поле `readonly isFipi: boolean` (по умолчанию трактуем `true`;
  для бонусов — `false`). Опционально `readonly bonusReason?: string` для бонусов.
- Прогресс кита считается **по опытам ФИПИ**: `total` = число ФИПИ-опытов комплекта
  (1→5, 2→7, 3→9, 4→6, 5→9, 6→4, 7→4); `done` = число ФИПИ-опытов в статусе DoD-ready.
  Бонусы в `total` НЕ входят (показываются отдельной меткой).
- `totalExperiments()` суммирует только ФИПИ-опыты; бонусы агрегируются отдельным счётчиком
  (для отображения «+N бонусов»).

**Содержимое.** `experiments[]` каждого кита переписывается под дословный перечень ФИПИ из
умбреллы §3. Бонусы добавляются с `isFipi: false` и `bonusReason`. Для kit-1/kit-2 статусы
проставляются по факту (см. ниже). kit-3..7 остаются `planned` с корректными ФИПИ-списками
(контент опытов — заглушки `status: planned`, но списки верные и помеченные).

**UI постер-карточки.** Бейдж «бонус» на опыте с `isFipi:false` в drawer; прогресс-кольцо
и «N/total опытов» считают по ФИПИ. (Минимальная правка рендера, без редизайна.)

### 2.2. Кит-1, опыт 1.5 — независимость F_арх от массы

**ФИПИ-якорь** (Прил. 2, компл. №1): «исследование … независимости выталкивающей силы от
массы тела (цилиндры №1 и 2)».

**Физика.** Цилиндр №1 (сталь, m≈195 г) и №2 (алюминий, m≈70 г), оба V≈25 см³. При полном
погружении F_арх = ρ_воды·g·V одинакова для обоих (≈0,245 Н), несмотря на разную массу.
Ученик измеряет вес в воздухе P_возд и в воде P_жид для каждого, считает F_арх = P_возд − P_жид,
сравнивает → вывод: F_арх от массы не зависит, зависит от объёма (равного).

**Реализация.** Новый экран `kit-1-hydrostatics/src/screens/independence-mass/` (id для
каталога — следующий за 1.x, отображается как «1.5»). Переиспользует физику архимеда
(`physics/archimedes/ArchimedesCalc.ts`) и приборы (`lab-dynamometer`, мензурка/стакан).
Журнал: `INDEPENDENCE_MASS_SPEC` (строки для цилиндров №1 и №2; колонки m [direct],
P_возд [direct], P_жид [direct], F_арх [derived = P_возд−P_жид], вывод о равенстве).
Инвариант фаззинга: |F_арх(№1) − F_арх(№2)| ≤ tolerance при равном V.

### 2.3. Кит-1, опыт 1.2 — укрепление

**Текущее (§30.3):** archimedes-экран = «только вода, полное погружение», 1.2 ⚠️ «частично»
(нет систематического сбора F_арх для цилиндров №2–4 как самостоятельного опыта).

**Решение.** Аудит archimedes-экрана: достаточно ли «режима 1.2» для DoD-опыта «измерение
архимедовой силы (цилиндры №2–4)» — серия измерений F_арх для трёх цилиндров с журналом.
Если режим 1.2 уже даёт серию по №2–4 — поднять статус до ✅ (только пометка + selfcheck-
инвариант). Если нет — добавить выбор цилиндра №2/№3/№4 и строки журнала на каждый (без
нового экрана; расширение существующего archimedes-режима «вода»). Объём правки определяется
аудитом на старте волны (фиксируется в плане).

### 2.4. Кит-2, опыт «измерение силы упругости одной точкой»

**ФИПИ-якорь** (КОДИФ §1.29, п.6): «…силы упругости…» (измерение, одной точкой через
динамометр). Не путать с бонусным `spring-work` (работа упругости).

**Физика.** Подвесить груз известной массы m на пружину → отсчёт силы упругости. При
равновесии F_упр = m·g (динамометр/расчёт). «Одной точкой» = единичное измерение, без серии.
Опционально сверка с k·Δl, если k известно.

**Реализация.** Отдельный минимальный экран `kit-2-forces/src/screens/elastic-force/`
(переиспользует `physics/spring/SpringModel.ts`, приборы `lab-stand`/`lab-spring-board`/
`lab-dynamometer`). Журнал `ELASTIC_FORCE_SPEC`: одна строка, колонки m [direct],
F_упр [derived = m·g/1000]. Отдельный экран выбран ради чистого ФИПИ-якоря, журнала и
selfcheck (а не mini-режим), как в эталоне density-solid.

### 2.5. Кит-2, аудит журнала `spring-work` (бонус)

Рекон пометил `spring-work` как journal v1 (кастом-HTML-таблица). REFERENCE §17.1 описывает
легальный паттерн «Custom Renderers поверх v2». **Задача-аудит:** определить, использует ли
`spring-work` v2-инфру (verifyRow/JournalSpec/record-mode) с кастом-рендерерами (§17.1 —
оставить как есть) или это настоящий v1-легаси (мигрировать на v2 custom-renderers ради
консистентности «полного канона»). Бонус остаётся `isFipi:false`. Объём — по результату аудита.
