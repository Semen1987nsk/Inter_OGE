## 2. ТЕХНИЧЕСКОЕ ОПИСАНИЕ ЭКСПЕРИМЕНТА

### 2.1 Физическая основа
**Закон Гука:** F = k × Δl  
где:
- F — сила упругости (Н)
- k — коэффициент жёсткости пружины (Н/м)
- Δl — удлинение пружины (м)

**Метод измерения:** Статический метод с подвешиванием грузов известной массы

### 2.2 Виртуальное оборудование (точная копия реального)

#### 2.2.1 Основное оборудование
1. **Штатив лабораторный**
   - Модель: по ГОСТ 25336-82
   - Высота: 60 см
   - Материал: сталь с порошковым покрытием
   - Основание: 20×15 см, утяжелённое

2. **Пружина №1 (жёсткость 50 Н/м)**
   - Материал: пружинная сталь
   - Естественная длина: 14 см
   - Рабочий диапазон: 14-25 см
   - Максимальная нагрузка: 5 Н
   - Крючки: верхний и нижний

3. **Пружина №2 (жёсткость 10 Н/м)**
   - Материал: пружинная сталь
   - Естественная длина: 14 см
   - Рабочий диапазон: 14-30 см
   - Максимальная нагрузка: 2 Н
   - Крючки: верхний и нижний

#### 2.2.2 Измерительные приборы
1. **Динамометр 0-1 Н**
   - Цена деления: 0.02 Н
   - Класс точности: 4
   - Погрешность: ±0.04 Н

2. **Динамометр 0-5 Н**
   - Цена деления: 0.1 Н
   - Класс точности: 4
   - Погрешность: ±0.2 Н

3. **Линейка миллиметровая**
   - Длина: 30 см
   - Цена деления: 1 мм
   - Погрешность: ±0.5 мм

#### 2.2.3 Грузы (точная масса по ФИПИ)
1. **Грузы с двойными крючками:**
   - 3 шт. × 100 г (±2 г)
   - Материал: латунь/сталь
   - Форма: цилиндрическая
   - Крючки: верхний и нижний для стыковки

2. **Наборные грузы:**
   - Штанга: 10 г (±0.5 г)
   - Диск 10 г: 10 г (±0.5 г)
   - Диск 20 г: 20 г (±1 г)
   - Диск 50 г: 50 г (±2 г)

### 2.3 Методика проведения эксперимента

#### 2.3.1 Подготовительный этап
1. Выбор пружины из комплекта
2. Закрепление пружины на штативе
3. Измерение естественной длины l₀
4. Выбор подходящих грузов

#### 2.3.2 Основные измерения
1. **Серия измерений с различными нагрузками:**
   - Груз 100 г: F₁ = 1.0 Н, измерение Δl₁
   - Груз 200 г: F₂ = 2.0 Н, измерение Δl₂
   - Груз 300 г: F₃ = 3.0 Н, измерение Δl₃
   - Наборные комбинации: 10-90 г с шагом 10 г

2. **Запись результатов в таблицу:**
   ```
   № | m (г) | F (Н) | l (см) | Δl (см) | k (Н/м)
   --|-------|-------|---------|---------|--------
   1 | 100   | 1.0   | 16.0    | 2.0     | 50
   2 | 200   | 2.0   | 18.0    | 4.0     | 50
   3 | 300   | 3.0   | 20.0    | 6.0     | 50
   ```

#### 2.3.3 Обработка результатов
1. Расчёт жёсткости для каждого измерения: k = F/Δl
2. Вычисление среднего значения: k_ср
3. Оценка погрешности измерений
4. Построение графика F(Δl)
5. Проверка линейности зависимости

### 3.2 Физический движок

#### 3.2.1 Основные расчёты
```javascript
// Удлинение пружины от массы груза
calculateElongation(mass, springConstant) {
    const force = mass * gravity; // F = mg
    return force / springConstant; // Δl = F/k
}

// Колебания с затуханием
springOscillation(k, m, x0, t) {
    const omega = Math.sqrt(k / m);
    const dampingCoef = 0.15;
    const amplitude = x0 * Math.exp(-dampingCoef * t);
    return amplitude * Math.cos(omega * t);
}
```

#### 3.2.2 Система единиц
- **Масштаб:** 40 пикселей = 1 см
- **Гравитация:** g = 9.8 м/с² (реальное значение)
- **Точность:** 0.1 мм для линейных измерений
