## 🚀 Как поднять новый опыт

Полный гайд — в [2-1-spring/REFERENCE.md, раздел 14](2-1-spring/REFERENCE.md). Кратко:

1. Скопируй `2-1-spring/` → `<номер>-<имя>/` (например `2-2-friction`).
2. Удали `node_modules/`, `dist/`, `test-results/`, специфичный код опыта (физика, оркестратор, типы state).
3. В `package.json` обнови `name`.
4. Прочитай ФИПИ-спеку и реальный комплект (`.business/Продукты/Програмное обеспечение/Виртуальная лаборатория по физике ОГЭ/ФИ-9 ОГЭ 2026_СПЕЦ.pdf`).
5. Согласуй с ПМ **5 property-инвариантов** (PI-1..PI-5) — это будут главные тесты опыта.
6. `npm install`, `npm run dev` — работаешь по эталону.
7. Перед сдачей — пройди [Definition of Done](2-1-spring/REFERENCE.md#13-definition-of-done) целиком.

## 🛠️ Стек

- **TypeScript 5.6 strict** — все новые опыты.
- **Vite 6** — dev-сервер и сборка.
- **Web Components (Shadow DOM)** — UI, без фреймворков (React/Vue не используем).
- **Vitest** — unit-тесты физики.
- **Playwright** — e2e + axe-core a11y.
- **CSS-переменные** — `tokens.css` копируется между опытами (общий design-system).
- **SVG** — все приборы (не Canvas — нужны резкие линии и a11y).
