Справка: Сила трения скольжения

Теория

Сила трения скольжения — сила, возникающая при скольжении одного тела по поверхности другого.

Закон Амонтона-Кулона:

Fтр = μ × N

где:

  • Fтр — сила трения скольжения (Н)
  • μ — коэффициент трения (безразмерный)
  • N — сила нормального давления (Н)

На горизонтальной поверхности: N = mg

Типичные значения μ

Дерево по дереву0.25 - 0.50
Дерево по пластику0.20 - 0.35
Дерево по резине0.40 - 0.70

Методика измерения

  1. Измерить массу бруска с грузами
  2. Равномерно тянуть брусок динамометром
  3. Записать показание в момент равномерного движения
  4. μ = Fтр / (m × g)
