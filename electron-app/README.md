# 📦 Сборка Windows приложения (.exe)

Эта папка содержит Electron обёртку для создания автономного приложения для Windows.

## 🔧 Архитектура

**Development режим**: Electron загружает файлы напрямую из родительской директории проекта. Никакого копирования файлов не требуется - все изменения сразу доступны.

**Production сборка**: При создании .exe файлов скрипт `copy-files.js` автоматически копирует актуальные файлы проекта.

## 🚀 Как запустить в режиме разработки

```bash
cd electron-app
npm install
npm start
```

## 📦 Как создать .exe файл

1. **Установите зависимости** (нужно сделать один раз):
   ```bash
   cd electron-app
   npm install
   ```

2. **Запустите сборку**:
   
   Для создания **Portable версии** (один файл, работает с флешки):
   ```bash
   npm run build
   ```

## 📂 Где искать результат?

После успешной сборки, готовый файл появится в папке:
`electron-app/dist/`

## 📁 Структура проекта

```
Inter_OGE/
├── index.html           # ← Основные файлы проекта
├── app.js               #    (НЕ дублируются!)
├── experiments/         #
├── assets/              #
│
└── electron-app/        # ← Только Electron-специфичные файлы
    ├── main.js          #    (загружает файлы из родительской папки)
    ├── package.json     #
    ├── copy-files.js    #    (используется ТОЛЬКО при сборке .exe)
    └── dist/            #    (сюда попадают готовые .exe)
```

## ⚠️ Важно

- **В режиме разработки** дублирования нет - Electron загружает файлы напрямую
- **При сборке .exe** файлы копируются автоматически скриптом `copy-files.js`
