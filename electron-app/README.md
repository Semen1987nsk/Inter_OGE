# 📦 Сборка Windows приложения (.exe)

Эта папка содержит всё необходимое для создания автономного приложения для Windows.

## 🚀 Как создать .exe файл

1. **Откройте терминал** в этой папке:
   ```bash
   cd electron-app
   ```

2. **Установите зависимости** (нужно сделать один раз):
   ```bash
   npm install
   ```

3. **Запустите сборку**:
   
   Для создания **Portable версии** (один файл, работает с флешки, не требует установки):
   ```bash
   npm run build
   ```
   
   Для создания **Установщика** (Setup.exe):
   ```bash
   npm run build:setup
   ```

## 📂 Где искать результат?

После успешной сборки, готовый файл появится в папке:
`electron-app/dist/`

Ищите файл с названием вроде: `Inter OGE Lab 1.0.0.exe`

## 🛠 Что происходит при сборке?

1. Скрипт `copy-files.js` автоматически копирует все актуальные файлы вашего веб-проекта (`index.html`, `js`, `css`, картинки) в эту папку.
2. `electron-builder` упаковывает всё это в исполняемый файл Windows.
